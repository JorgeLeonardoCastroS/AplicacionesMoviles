## 2. Descripción del proyecto:
En este proyecto se está probando el análisis de requisitos, creación de lista de comprobación de la app, y pruebas de la app.

Pruebas manuales de aplicaciones moviles:
1. se está probando puntos de recogida.
2. se está probando la elección de polatillos.
3. se está probando la confirmación del pedido.
4. se está probando la pantalla de seguimiento de pedidos y su recogida.
5. se está probando el envío del pedido.

Necesitas tener instalados android studio y paquete de office o google sheets.
Ejecuta todas las pruebas manuales y genera informe de errores.
Ejecuta las pruebas automatizadas.
